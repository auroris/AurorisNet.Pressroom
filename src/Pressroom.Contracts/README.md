# Pressroom.Contracts

Shared request/response DTOs and validation helpers (`RenderRequest`, `IPdfRenderer`, `PdfRenderResult`, job records, `RequestValidator`, `JsonDefaults`) for .NET 8 and .NET 10.

Not published separately—bundled inside [`AurorisNet.Pressroom.Client`](https://github.com/auroris/AurorisNet.Pressroom/blob/main/src/Pressroom.Client/README.md). See the [API reference](https://github.com/auroris/AurorisNet.Pressroom/blob/main/docs/development/api.md).
